## Objetivo

Instalar Immich en Docker aparte de AIO: miniaturas, recodificados y base de datos en el SSD
(`/srv/immich`), subidas de los móviles en `Imagenes/Moviles` del pool, volcado diario de PostgreSQL a
las 23:00 en `Archivo/immich-db` (14 copias), biblioteca externa `Imagenes` en solo lectura sin
`Moviles`, tareas nocturnas a las 00:00, primera clasificación con ML remoto en el PC de
persona 1, apps de los móviles con Cámara y WhatsApp, y la limpieza `immich-limpieza` a las 00:30
que solo archiva y añade al álbum «Revisar», sin permiso de borrado (HLD §6, §7, §9, ADR-011,
ADR-012, ADR-013). No es una fase de la guía: se numera 15 y se ejecuta tras los RBK 10 y 14.

## Prerrequisitos

- [ ] RBK 10 y 14 completados (Docker, pool y Tailscale)
- [ ] Contraseña de la base de datos de Immich y del admin de Immich creadas en el gestor de contraseñas
- [ ] PC de persona 1 con Docker instalado para el ML remoto
- [ ] Sesión iniciada por el usuario en la web de OMV

### Paso 19: Instalar el script immich-limpieza

| Campo | Valor |
|---|---|
| **Riesgo** | Cambio |
| **Ejecuta** | Agente |
| **Dónde** | NAS por SSH |
| **HLD** | §6, ADR-013 |

Comando:

```bash
ssh nas 'sudo tee /usr/local/sbin/immich-limpieza' <<'EOF'
#!/usr/bin/env python3
"""immich-limpieza: añade al álbum "Revisar" y archiva memes, comida y capturas.
Nunca borra (HLD §6, ADR-013). Uso: immich-limpieza [--simular]"""
import json
import sys
import time
import urllib.request

URL = "http://localhost:2283/api"
CLAVE = open("/etc/immich-limpieza/api.key").read().strip()
CONSULTAS = ["meme", "plato de comida", "captura de pantalla"]
MAX_POR_CONSULTA = 50          # se fija en el paso de calibración
ALBUM = "Revisar"
REGISTRO = "/var/log/immich-limpieza.log"
SIMULAR = "--simular" in sys.argv


def api(metodo, ruta, cuerpo=None):
    if metodo == "DELETE":
        raise SystemExit("immich-limpieza nunca borra")
    datos = None if cuerpo is None else json.dumps(cuerpo).encode()
    req = urllib.request.Request(URL + ruta, data=datos, method=metodo, headers={
        "x-api-key": CLAVE, "Content-Type": "application/json", "Accept": "application/json"})
    with urllib.request.urlopen(req, timeout=120) as r:
        texto = r.read()
    return json.loads(texto) if texto else None


def candidatos():
    ids = {}
    for q in CONSULTAS:
        r = api("POST", "/search/smart", {"query": q, "size": MAX_POR_CONSULTA, "page": 1})
        for a in r["assets"]["items"]:
            ids[a["id"]] = q
    r = api("POST", "/search/metadata", {"originalFileName": "Screenshot", "size": 1000, "page": 1})
    for a in r["assets"]["items"]:
        ids[a["id"]] = "Screenshot"
    return ids


def album_revisar():
    for a in api("GET", "/albums"):
        if a["albumName"] == ALBUM:
            return a["id"]
    return api("POST", "/albums", {"albumName": ALBUM})["id"]


def main():
    ids = candidatos()
    marca = time.strftime("%Y-%m-%d %H:%M:%S")
    with open(REGISTRO, "a") as log:
        for i, motivo in ids.items():
            log.write(f"{marca}\t{'SIMULADO' if SIMULAR else 'ARCHIVADO'}\t{motivo}\t{i}\n")
    print(f"{len(ids)} candidatos{' (simulación)' if SIMULAR else ''}")
    if SIMULAR or not ids:
        return
    album = album_revisar()
    lista = list(ids)
    api("PUT", f"/albums/{album}/assets", {"ids": lista})
    api("PUT", "/assets", {"ids": lista, "visibility": "archive"})


if __name__ == "__main__":
    main()
EOF
ssh nas 'sudo chmod 755 /usr/local/sbin/immich-limpieza && sudo python3 -m py_compile /usr/local/sbin/immich-limpieza'
```

Esperado: `/usr/local/sbin/immich-limpieza` (755, root) que nunca llama a DELETE; `python3 -m py_compile` sin errores.

Si falla: si `py_compile` falla, corrige el fichero.

## Vuelta atrás

- Limpieza: `/var/log/immich-limpieza.log` guarda cada ID con fecha. Para deshacer una ejecución,
  quitar esos ID del álbum «Revisar» y devolverlos a la línea de tiempo (en la web de Immich:
  Archivo → seleccionar → Desarchivar; o con la API `PUT /api/assets` con `visibility: timeline`).
  Desactivar: `ssh nas 'sudo systemctl disable --now immich-limpieza.timer'`.
- Immich entero: Abajo en el compose de OMV. Las fotos de `Imagenes/Moviles` y los volcados
  quedan en el pool; `/srv/immich` (miniaturas y base de datos) se puede borrar a mano (lo hace el usuario).
- La biblioteca externa es de solo lectura: Immich nunca modifica `Imagenes`.
